## Une section

Les paragraphes, le **gras**, l’*italique*, les [liens](https://astro.build) et le `code en ligne` fonctionnent, tout comme les listes :

- un premier élément
- un deuxième élément

> Une citation, pour citer quelqu’un.

```python
def greet(name: str) -> str:
    return f"Bonjour, {name} !"
```
